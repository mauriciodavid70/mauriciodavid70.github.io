Política de privacidad

Última actualización: 14 de noviembre de 2026

"Planificador Homeschool" es una aplicación privada de una sola familia. Solo la usan cuentas autorizadas por la familia.

Qué datos usa

Accede únicamente a los archivos de una carpeta específica de Google Drive de la familia ("Homeschool Antonia") para leer y crear planes, documentos y registros de práctica. No accede a correo, calendario, contactos ni a otros archivos.

Cómo se usan

Los datos se usan solo para preparar y guardar materiales educativos para la familia. No se venden, no se comparten con terceros para publicidad y no se usan para entrenar modelos. El texto se procesa con un proveedor de modelos de IA (OpenAI API) únicamente para generar las respuestas.

Datos de menores

Se minimizan los datos personales de menores de edad, conforme a la Ley 1581 de 2012 de Colombia. No se recopilan datos sensibles.

Uso de datos de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.

Retiro del acceso

El acceso puede revocarse en cualquier momento en myaccount.google.com/permissions.

Privacy policy

"Planificador Homeschool" is a private app used by a single family and only by accounts that family authorizes. It accesses only the files in one specific Google Drive folder ("Homeschool Antonia") to read and create plans, documents and practice logs. It does not access email, calendar, contacts or other files. Data is used only to prepare and store educational materials for the family; it is not sold, not shared with third parties for advertising, and not used to train models. Text is processed by an AI model provider (OpenAI API) solely to generate responses. Personal data about minors is minimized, in line with Colombia's Law 1581 of 2012. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: nanahomeschool74@gmail.com
